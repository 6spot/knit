# 子任务清单

按 `design.md` 拆出的 42 个子任务，分 8 批；另有排在切换之后的任务（见「之后」）。用户已于 2026-11-15 确认清单，并决定分批登记：做到哪一批登记哪一批。A 批、B 批已完成并交付，C 批已登记（2026-11-15）。每个任务开始前仍要取得用户授权。

## 约定

- 新代码放在 `next/`（源码、测试、模板），用 `npm run test:next` 验证。旧的 `npm test` 在切换前保持全绿。
- 每个任务按 `.knit/standards/task-splitting.md` 拆，正文按 `.knit/standards/task-writing.md` 写：执行者只拿到仓库和这份 `task.md` 就能做完，不按谁做、在哪做区分写法。
- 标了「独立审查」的任务由另一个执行者审查，其余自查。
- 同一批内按编号先后做；后一批依赖前一批。
- 切换之前所有任务由旧 Knit 管理，每个任务的交付是 3 次提交，42 个任务约 126 次提交。
- 规范文件只在没有任务处于“已检查、未交付”时写：旧 Knit 发现规范变了，会把已有的检查判为过期。
- A1、H1、H3 涉及全局安装、真实模型和手工提交，开始前单独取得授权。
