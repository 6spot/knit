# 047 实现主会话每轮任务上下文与工作流注入

- 里程碑：首版主会话与规划补齐
- 执行角色：Pi宿主桥接 Agent
- 来源：[044共同契约](044-main-agent-workflow-contract.md)、[046上下文加载](046-role-aware-task-context.md)。
- 实际依赖：044的主会话语义、046的上下文接口、005验证过的宿主公开能力及现有会话选择／关联接口；目标Pi版本与事件约束核对[052](052-pi-1-5-compatibility-and-capabilities.md)的结论。不要求027–043全部完成后才开始局部开发，公开能力可先核对、最终验收使用目标版本。
- 唯一状态入口：[TASKS.md](../TASKS.md)。

## 目标与范围

让主Agent在每轮处理用户需求前获得当前任务、阶段、资料入口和下一步规则。补齐对话工作流的宿主入口，明确上下文引导与已有工具副作用守卫的职责。

## 先读

遵守仓库入口、044与046。实施宿主变更前完整阅读相关Pi公开Extension／事件文档及示例，核对当前安装版本；读取桥接模板、session-service、上下文与现有宿主测试。

## 必需工作

- 使用宿主公开的模型调用前事件或等效能力接入，不预设必须有名为input的硬拦截接口；核实事件顺序、消息范围、异步读取和返回格式。
- 注入当前选定任务的稳定身份、phase／业务摘要、待决项、草案／活动运行的必要摘要及角色资料入口；无任务时提供相应入口规则，不虚构任务状态。
- 任务切换、换Session、资料更新或取消后，下轮获取最新适用信息；不把旧任务上下文持续叠加，不重复注入不断增长的正文。
- 模型调用前刷新观察信息，实际写动作仍通过核心重新核对授权、阶段、锁和版本；不把提示词当作副作用安全边界。
- 正常闲聊、查询和轻量修改保持可用，不强制先建正式任务；缺失／不可信初始化或公开能力不可用时按既有准入报告具体原因。
- 在受管桥接源模板实现并补适配验证；安装包生成和已有项目升级的一致性由050复核。

## 交付与完成条件

- 在隔离初始化项目里验证宿主实际触发和主Agent实际收到的上下文，至少覆盖无任务、已选任务、任务切换与跨Session继续。
- 验证重复轮次不无限堆叠内容，更新后不串用旧阶段／旧任务，活动run范围不被注入更新改写。
- 记录宿主版本、公开API、实际验证方式与限制；局部适配替身不能替代必需的真实宿主最小验证。
- 运行相称的桥接与会话回归；不以任务工具注册成功代替每轮注入验收。

## 边界

不引Pi SDK／RpcClient、不建模型运行时，不默认多跑一轮模型，不在真实项目自动改写已生成桥接。本项提供入口，任务分类与规划行为分别由048／049实现。
