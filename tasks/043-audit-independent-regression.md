## 必需复验

- 检查、接收和交付核实当前成果字节／类型／执行位，旧 pass 不能认可检查后的新增变化。
- 准备、worker 与接收核实实际分支；真实持锁 worker 期间草案可保存／撤回，应用后磁盘状态与响应一致。
- 角色／工作流／运行指令进入实际输入身份，恢复与交付同步核实版本。
- 规定的凭据扫描、规范目标真实路径与私有运行资料权限都在实际副作用边界生效。
- 不按固定阶段总时长停止；prefer 恢复的身份、锁、新旧会话与来源映射正确。
- 未归档 completed 更新、授权规范成果、候选版本与正文／索引部分成功重试符合原始规则。
- init 升级中断可据持久基线继续，归档任务概览及 Pi slash 查询可展示真实数据。
- 运行类型检查、构建、受影响回归与完整离线测试、包检查；按任务要求补真实 Pi 适配／宿主最小验证。真实验证未执行时如实标明，不能用 fake 冒充通过。
- 检查生成模板与源码装配、安装包的一致性，确认修复未引入新的越界写入或无关 index 改动。

## 交付与完成条件

- 在新的验证目录保存基线提交／工作区摘要、环境、实际命令、结果及逐发现验收映射；原审计基线证据按事实保留。
- 针对原复现条件写有业务意义的修复断言，不把审计探针的框架 pass 当修复成功。
- 更新 TASKS.md 及相关当前就绪声明；原16项审计结论与新增[051工作流验收](051-main-workflow-independent-gate.md)分别报告，共同约束首版就绪。不追改原历史测试数字或隐藏未完成项。
- 若仍有必需缺口，给出具体失败条件与任务关联，按规则记录阻塞并继续可审部分，不将本项标 completed。

## 边界

- 不提交、推送、发布、修改真实项目历史或扩大到 macOS／Worktree 等明确延期范围。
- Git及故障实验只在隔离夹具；保留其它执行者工作，避免复用正在并发变动的 dist 作为稳定基线。
- 待补证据按事实交接，不重复请求已有授权，不将新决策需求默认为已批准。
